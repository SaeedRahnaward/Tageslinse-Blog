# Tageslinse-Blog

Ratgeberartikel „Tageslinsen oder Monatslinsen?“ als Blogseite im Gestaltungssystem von Gilga Optik.

- `index.html` — der vollständige Artikel (statisches HTML, kein Build nötig)
- `css/tokens.css` — Farben, Abstände, Radien und Schriften aus `design/tokens.json`, mit hellem und dunklem Theme
- `css/blog.css` — Komponenten mit dem Präfix `gb-` (lädt Fraunces und Figtree von Google Fonts)
- `design/tokens.json` — die Design-Tokens als Quelle

Lokal ansehen: `index.html` im Browser öffnen oder `npx http-server .` ausführen.
